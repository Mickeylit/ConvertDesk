ConvertDesk 0.2 — macOS 使用说明

安装与启动
1. 打开 DMG，将 ConvertDesk.app 拖入“应用程序”。
2. 打开 ConvertDesk。当前本地构建使用 ad-hoc 签名，尚未经过 Apple 公证；
   如果 macOS 阻止首次启动，在“系统设置 → 隐私与安全”中允许打开。
3. 窗口内拖放或选择文件可直接使用，不要求辅助功能权限，无需重启电脑。

转换文档
1. 把 HTML、PDF、PPTX、DOCX、TXT 文件拖入窗口，或点击“选择文件”。
2. 选择目标格式，再点击“开始转换”。支持一次添加多个文件。
3. 结果默认保存在原文件旁；原文件保留，重名结果自动编号。
   转换后可点击“打开文件夹”。顶部“设置 → 通用”可调整输出位置。

转换边界
- PDF 转 PPTX：每页是一张图片幻灯片，页内文字不可编辑。
- HTML、DOCX、TXT 转 PPTX：生成可编辑内容，但会重新排版。
- 扫描 PDF 没有文字层时，须先使用 OCR 工具识别文字。
  当前主工作台不会自动识别扫描件，也未提供 OCR 开关。
- 复杂表格、公式、字体、动画和网页 CSS 不保证完全保留。

可选的 Finder 快捷方式
按住 Option 拖动文件唤出圆环，需要在设置中启用对应触发方式，
并在“系统设置 → 隐私与安全 → 辅助功能”中允许 ConvertDesk。
这是可选快捷方式，不影响窗口内的普通转换。
若重装后全局快捷方式失效，可删除旧权限项，再添加当前 ConvertDesk.app。
